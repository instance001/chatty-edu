# Revision Sprint (Demo)

`Revision Sprint (Demo)` is a student-friendly sample module for planning a focused revision block.

## What it shows

- a portable hosted webview module
- student-safe standalone use in a browser
- a simple bridge summary so Chatty-EDU can understand the current revision plan

## Standalone use

Open `web/index.html` in a browser. The page stores its own draft locally in the browser.

## Hosted use

Place the folder in `chatty-edu/modules/` and open it from the Modules menu. The UI stays the same, but hosted mode lets Chatty-EDU read the current revision snapshot when needed.
